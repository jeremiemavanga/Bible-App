# Practice focus and reference recall — 1.2.0

2 November 2026. Publication follows the verified main-branch deployment.

## Focus on the passage

Starting an automatic practice session opens a dedicated focus layout. It omits the global header/navigation, calendar, project metrics, phase counters, repeated save confirmations and routine update/reminder interruptions. The existing paper-and-ink design, flowing verse text and subtle word difficulty colours remain.

Pause stays available, including with a short keyboard-height viewport or enlarged text. The focused typing field stays within the visible viewport as full words unfold in long passages. Its pause sheet contains Continue, Finish for now and optional advanced tools. Finishing/pause exit restores normal application navigation. Storage failures remain visible. Existing audio is paused when focused practice begins; it does not automatically restart afterward.

The reference remains visible as a cue during wording practice, as the user requested. It disappears for the reference question, including from paused context and accessible labels. Correct initials still reveal complete words. First-letter wording recall remains self-assessed rather than automatically verified full-word knowledge.

## Words first, then where to find them

After the wording result is saved, the next task asks for the book, chapter and verse. Equivalent capitalization, spacing and known aliases are accepted; wrong chapters, verse numbers, lists and ranges are rejected for a single-verse question. A multi-verse exercise explicitly asks where the passage **begins** and tests only its starting address.

Wording and reference attempts have independent schedules. An incorrect address or reference Help does not undo the wording review, alter its next due date or lower its memorized status. The reference returns sooner under its own gradual schedule. When only the reference is due, a short reference-only visit shows the verse and asks for its address, without requiring another wording test.

A first mistaken submission remains a failed reference encounter even if corrected during the same visit. Explicit Help is recorded separately from ordinary mistakes. Retries and reloads do not create duplicate reviews or repeatedly reschedule the same encounter. A reference can be corrected after Help to reinforce the association.

## Preserving progress

The app keeps its existing URL, installation, database and wording history. Reference schedules begin from actual reference practice; no reference knowledge is invented for earlier verses. Existing drafts remain supported. New drafts preserve the partial reference input, challenge phase, error/help information and reference-only queue flags, including offline recovery and encrypted transfer.

Reference results are kept out of typed wording-accuracy statistics and verse memorized counts. Optional Progress insights expose reference performance and due dates separately from word difficulty.

Backups with these new reference phases/results need 1.2.0 or newer. Earlier backups remain importable. This does not add accounts or automatic cross-device synchronization.

## Content and installation

No new audio recording or translated text is bundled by this update. KJV source integrity, attribution, territorial-rights notices and authorized-import requirements remain unchanged. The separate audio/translation assessment still requires verification of the exact package and offline grant.

After a successful GitHub Pages deployment, open the existing installed app while online and accept its update/reload prompt. Do not change the site origin or remove the installation to receive this update.
